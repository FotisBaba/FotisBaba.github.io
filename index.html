Master's thesis · Technical University of Crete · School of ECE · 2024

VRPG: build worlds together, then play them

A networked VR platform I built solo. In creator mode, friends shape a world together. In play mode, one of them becomes the Game Master and narrates while the others fight through it as wizards. Evaluated with users and tested on Oculus Rift S and Quest 2.

Read the thesis on GitHub →

World creator

Networked terrain tools (raise, flatten, smooth, stamp heightmaps, paint textures and holes) plus trees, water, objects, sound zones and NPCs. An object editor handles multi-object edits. Worlds save as JSON locally and to Firebase.

Combat and AI

Fireball and call-lightning spells, crafting, character attributes and levelling, and a boss with nested state machines and attack patterns. Enemies navigate with NavMesh pathfinding.

Game Master tools

Live terrain editing during play, an item spawner, and an audio mixer for narration. A non-linear demo level, tested with volunteer players.

How it's put together

Ability system
Custom ability system component and attribute set, with damage resolved in a gameplay effect execution calculation (GEExecCalc_DamageTaken).
Combat components
A shared pawn combat component, with hero and enemy subclasses, registers weapons by gameplay tag, toggles weapon collision and reports hits.
Data-driven start-up
Hero and enemy start-up data assets grant abilities and effects on spawn, so new characters need data, not code.
Input through gameplay tags
Enhanced Input actions mapped to gameplay tags in a data asset and routed to abilities by a custom input component.
Animation
Base and hero anim instances with linked anim layers per weapon.
